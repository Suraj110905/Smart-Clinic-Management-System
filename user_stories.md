# Smart Clinic Management System - User Stories

## Patient User Stories

1. As a Patient, I want to register an account so that I can access the system.

2. As a Patient, I want to log in securely using email and password.

3. As a Patient, I want to search doctors by speciality.

4. As a Patient, I want to book appointments with doctors.

5. As a Patient, I want to view my appointment history.

6. As a Patient, I want to receive prescriptions from doctors.

---

## Doctor User Stories

1. As a Doctor, I want to log in securely.

2. As a Doctor, I want to manage my availability timings.

3. As a Doctor, I want to view all booked appointments.

4. As a Doctor, I want to create prescriptions for patients.

5. As a Doctor, I want to access patient details during consultation.

---

## Admin User Stories

1. As an Admin, I want to add doctors to the system.

2. As an Admin, I want to manage doctor records.

3. As an Admin, I want to monitor appointments.

4. As an Admin, I want to manage patient records.

5. As an Admin, I want to maintain system security and access control.
